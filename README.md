# kajenn-gramlot

**Gramlot applications for [kajenn](https://github.com/kajenn-org/kajenn), with
[asqueel](https://github.com/asqueel-org/asqueel).** The base for new
applications written on kajenn, asqueel and
[gramlot](https://github.com/gramlot-org/gramlot).

**Status**: Pre-Alpha. Nothing is implemented yet.

## Two applications

| Application | Runs on | Register of users, connections and pages |
|---|---|---|
| minimal | kajenn, one process | no |
| orchestra | [kajenn-orchestra](https://github.com/kajenn-org/kajenn-orchestra), worker pool | yes |

The minimal application is built first.
